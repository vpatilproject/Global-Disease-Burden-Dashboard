# Global Disease Burden Dashboard

## 📌 Project Overview

The **Global Disease Burden Dashboard** is a Tableau-based data visualization project designed to analyze major causes of death globally and understand how disease-related mortality changes over time and across countries.

The dashboard provides interactive visualizations for comparing major causes of death, analyzing disease trends, and exploring the geographic distribution of mortality.

## 🎯 Project Objectives

- Identify the major causes of death globally.
- Analyze disease-related mortality trends over time.
- Compare mortality across different disease categories.
- Visualize disease-related deaths across countries using a world map.
- Enable interactive exploration using Year, Country, and Disease Type filters.

## 🛠️ Tools & Technologies

- **Visualization:** Tableau
- **Data Analysis:** Tableau
- **Dataset:** Annual Number of Deaths by Cause
- **File Format:** CSV
- **Documentation:** GitHub / Markdown

## 📊 Dashboard Components

### 1. Top Causes of Death

Visualizes and compares the major causes of death to identify which causes contribute most to global mortality.

### 2. Disease Trend Analysis

A time-series visualization showing how deaths caused by major diseases change over the years.

The analysis focuses on major causes such as:

- Cardiovascular Diseases
- Neoplasms (Cancer)
- HIV/AIDS
- Diabetes

### 3. Global Disease Map

A geographic visualization showing disease-related deaths across countries.

The map allows users to explore the geographic distribution of mortality.

### 4. Interactive Filters

The dashboard includes filters for:

- **Year**
- **Country**
- **Disease Type**

These filters allow users to interactively explore the data and analyze specific periods, countries, and disease categories.
